# نسخ Firestore الاحتياطية واستعادة البيانات

## خيار الخطة المجانية

لا تستخدم سكربت الجدولة في خطة Spark؛ جداول النسخ المدمجة تتطلب Blaze، وتُحسب رسوم تخزين النسخ والاستعادة. لتنزيل نسخة مجانية يدويًا، سجّل الدخول كمدير وافتح لوحة الإدارة ثم اضغط **نسخة احتياطية**. سينزّل المتصفح ملف JSON يحتوي على سجلات الطلاب والتقدم والأكواد المحفوظة. الملف يحتوي بيانات حساسة؛ خزّنه في مكان خاص وآمن.

التصدير اليدوي يقرأ سجلات الطلاب من Firestore، لذلك استخدمه عند الحاجة واحتفظ بالملف خارج مجلد النشر. لا يوفر هذا الخيار نسخًا تلقائيًا أو مجدولًا.

## سياسة النسخ

- هذا القسم يشرح الخيار المدفوع للنسخ المُدار المجدول في Blaze.
- مدة الاحتفاظ الافتراضية 14 يومًا، ويمكن تغييرها إلى مدة من يوم واحد حتى 14 أسبوعًا.
- Firestore يحدد وقت إنشاء النسخة تلقائيًا؛ لا يمكن اختيار ساعة محددة.
- الاستعادة تنشئ قاعدة بيانات جديدة. اختبر الاستعادة إلى قاعدة منفصلة قبل تحويل التطبيق إليها.

## تفعيل الجدول

يتطلب ذلك تفعيل فوترة Google Cloud (خطة Firebase Blaze)، وتثبيت Google Cloud CLI، وتسجيل الدخول بحساب يملك صلاحية `roles/datastore.backupSchedulesAdmin` على المشروع.

شغّل من مجلد المشروع، مع التأكد من استخدام مشروع الإنتاج وقاعدة البيانات المقصودة:

```powershell
./scripts/create-firestore-backup.ps1 `
  -ProjectId 'logical-delight-5vr20' `
  -DatabaseId 'ai-studio-mahmoudibrahim-f38dbd15-ea18-4a67-962f-bcba77618734'
```

يمكن تحديد مدة مختلفة، مثل `-Retention '28d'`. يفحص السكربت الجداول الموجودة ويتجنب إنشاء جدول يومي مكرر.

تحقق من الإعداد والنسخ التي أُنشئت:

```powershell
gcloud firestore backups schedules list `
  --project='logical-delight-5vr20' `
  --database='ai-studio-mahmoudibrahim-f38dbd15-ea18-4a67-962f-bcba77618734'

gcloud firestore backups list --project='logical-delight-5vr20'
```

تُفرض رسوم على تخزين النسخ وعلى عملية الاستعادة. راجع تقدير التكلفة في Google Cloud قبل التفعيل.

## اختبار الاستعادة

1. اختر نسخة من مشروع Google Cloud.
2. استعدها إلى قاعدة بيانات جديدة بمعرّف منفصل.
3. تحقّق من عدد السجلات، وأكواد الطلاب، والتقدم، والملاحظات، ومسودات الأكواد.
4. وثّق خطوات التحويل إلى قاعدة الاستعادة وخطوات الرجوع إلى القاعدة الأصلية.

لا يحوّل التطبيق تلقائيًا إلى قاعدة مستعادة؛ يجب تحديث `firestoreDatabaseId` في إعداد Firebase بعد نجاح التحقق من الاستعادة.
